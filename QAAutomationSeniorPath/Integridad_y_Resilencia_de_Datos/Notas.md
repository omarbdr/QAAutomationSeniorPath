Módulo 2: Integridad y Resiliencia (Manejo de Excepciones)
¿Qué vas a aprender?

Bloques try-catch: El escudo protector de tu código.

Excepciones Específicas: Aprender a identificar qué tipo de error ocurrió (¿Fue un formato malo? ¿Fue un valor nulo?).

Flujo de Continuidad: Cómo evitar que un error en un elemento de una lista detenga el procesamiento de los demás.

¿Cómo te prepara para QA Automation?
Imagina que estás automatizando una prueba que lee 100 números de cuenta de un archivo Excel 
para ingresarlos en un portal bancario. Si la cuenta #15 tiene una letra por error, no quieres que el test 
se muera ahí. Quieres que el log diga: "Fila 15: Error de formato", y que el script continúe con la #16.
